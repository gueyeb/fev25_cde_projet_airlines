# Archives de Documentation

Ce dossier conserve les fichiers Markdown retirés mais utiles pour l'historique. Lors d'un archivage :

1. Ajouter une mention `Archivé (YYYY-MM-DD)` en haut du fichier avec le lien vers la source canonique.
2. Garder le nom d'origine (ou suffixe `_FR` pour les traductions) afin de rester facilement retrouvable.
3. Mettre à jour `AGENTS.md` si l'emplacement de référence change.

- `CLAUDE.md` → remplacé par `AGENTS.md`.
- `GUIDE_PREFECT_FR.md` → remplacé par `PREFECT_GUIDE.md` (FR) + `prefect_flows/README.md`.
- `ORCHESTRATION_WORKFLOW_FR.md` → remplacé par `WORKFLOW_ORCHESTRATION.md`.
